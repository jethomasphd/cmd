# Symposium Log

*Use this to record a working in which more than one persona is present. A symposium is an
exceptional event — convene it only when a claim must cross several boundaries at once, or
when a problem is genuinely multi-disciplinary. The log is itself a CMD artifact: it carries
provenance, and it is what remains when the personas are released.*

For a worked example, see [`docs/05-the-summoning.md`](../docs/05-the-summoning.md).

---

```
SYMPOSIUM PROVENANCE
  symposium id:       <e.g. SYM-003>
  matter:             <one line — the problem the symposium was convened to work>
  why a symposium:    <why no single artifact or single persona could carry this load>
  orchestrator:       <the human who moderates and decides>
  personas summoned:  <name — calibrated for which boundary>; <name — ...>  (max 5)
  protocol:           COMPANION v2.0
  version:            <v1.0, ...>
  date / status:      <date> · <in session | shipped>
```
